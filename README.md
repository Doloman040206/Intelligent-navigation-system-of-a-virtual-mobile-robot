# Інтелектуальна система навігації віртуального мобільного робота з урахуванням погодних умов (Python + OpenStreetMap + Open-Meteo)

## 📌 Опис роботи

Дана робота реалізує інтелектуальну систему навігації віртуального мобільного робота в міському середовищі з урахуванням погодних умов.

Система забезпечує отримання географічних даних про дорожню мережу, аналіз погодних параметрів, оцінювання ризиків пересування та побудову маршрутів між заданими початковою і кінцевою точками.

Для пошуку маршрутів використовується алгоритм Дейкстри, реалізований у двох варіантах: базовому та адаптивному. Базовий підхід враховує довжину дорожніх сегментів, тоді як адаптивний додатково враховує оцінений рівень ризику.

Додаток написаний мовою Python і призначений для дослідження можливостей інтелектуальної адаптації навігації до змін зовнішніх умов.

## 🎯 Функціональні можливості

### 🗺️ Побудова маршрутів

- вибір міського сценарію навігації;
- визначення початкової та кінцевої точок маршруту;
- підтримка пішохідного та автомобільного режимів пересування;
- отримання дорожньої мережі з OpenStreetMap;
- представлення дорожньої мережі у вигляді графа;
- пошук маршруту за допомогою алгоритму Дейкстри.

### 🌦️ Аналіз погодних умов

Система враховує такі погодні параметри:

- температуру повітря;
- кількість опадів;
- швидкість вітру.

На основі отриманих значень визначається рівень ризику кожного погодного фактора та розраховується інтегральна оцінка погодного ризику.

Передбачено два способи отримання погодних даних:

- актуальні погодні дані через Open-Meteo API;
- контрольовані погодні сценарії для експериментального дослідження.

### 🧠 Інтелектуальний модуль прийняття рішень

- оцінювання ризику температурних умов;
- оцінювання ризику опадів;
- оцінювання ризику швидкості вітру;
- розрахунок загального погодного ризику;
- визначення категорії погодних умов;
- формування рекомендації щодо режиму пересування.

### 🛣️ Базове та адаптивне планування маршрутів

У системі реалізовано два підходи до пошуку маршруту:

**Baseline (базовий підхід):**
- використовує алгоритм Дейкстри;
- мінімізує загальну довжину маршруту;
- не враховує оцінений ризик дорожніх сегментів.

**Adaptive (адаптивний підхід):**
- використовує алгоритм Дейкстри;
- враховує довжину та оцінений ризик дорожніх сегментів;
- змінює вагу ребер графа відповідно до рівня ризику;
- намагається знайти маршрут із меншим модельованим ризиком.

В цілому, адаптивний підхід може обрати довший маршрут, якщо він має нижчу оцінку ризику. Якщо ж дорожня мережа не містить відповідних альтернатив, то обидва підходи можуть сформувати однаковий маршрут.

### 📊 Експериментальне дослідження

- моделювання сприятливих, помірних і несприятливих погодних умов;
- порівняння Baseline та Adaptive;
- оцінювання довжини побудованих маршрутів;
- порівняння середнього модельованого ризику;
- аналіз розрахункової вартості маршрутів;
- вимірювання часу планування;
- перевірка успішності побудови маршрутів.

### 🗺️ Візуалізація

- формування інтерактивної карти маршрутів;
- відображення дорожньої мережі;
- позначення початкової та кінцевої точок;
- відображення побудованого маршруту;
- використання Leaflet для візуалізації географічних даних.

Окремо ще передбачено використання актуальних погодних даних, отриманих через Open-Meteo API.

## 🧮 Математична модель оцінювання ризику

Для визначення загального погодного ризику використовується зважена сума трьох складових:

**R = 0.25 × Rₜ + 0.45 × Rₚ + 0.30 × Rᵥ**

де:

- Rₜ — ризик, пов'язаний із температурою;
- Rₚ — ризик, пов'язаний з опадами;
- Rᵥ — ризик, пов'язаний зі швидкістю вітру.

Для класифікації погодних умов використовуються такі порогові значення:

- R < 0.20 — сприятливі умови;
- 0.20 ≤ R < 0.50 — помірні умови;
- R ≥ 0.50 — несприятливі умови.

Для адаптивного планування використовується вагова функція дорожнього сегмента:

**W(e) = L(e) × (1 + α × R(e))**

де:

- W(e) — адаптивна вага ребра графа;
- L(e) — довжина дорожнього сегмента;
- R(e) — оцінений ризик дорожнього сегмента;
- α — коефіцієнт впливу ризику (у проєкті α = 2.0).

## 🧱 Архітектура проєкту

Програмна система має модульну структуру та складається в нас з таких основних компонентів:

- **main.py** — головний файл запуску та координації роботи системи;
- **config/** — конфігураційні параметри та опис міських сценаріїв;
- **services/** — отримання погодних і географічних даних;
- **core/** — інтелектуальна оцінка ризиків, прийняття рішень і планування маршрутів;
- **experiments/** — формування контрольованих сценаріїв, проведення експериментів та розрахунок метрик;
- **visualization/** — створення інтерактивних карт;
- **tests/** — автоматизовані тести основних компонентів;
- **outputs/** — результати роботи системи.

## ⚠️ Обмеження системи

- дорожня мережа залежить від повноти та актуальності даних OpenStreetMap;
- система в нас не моделює як таку фактичну інтенсивність дорожнього руху, тимчасові перекриття, аварії та повний стан дорожнього покриття;
- адаптивний алгоритм обмежений наявними альтернативами у графі дорожньої мережі;
- отримані результати залежать від обраного міста і самого режиму пересування.
